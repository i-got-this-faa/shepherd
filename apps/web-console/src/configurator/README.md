# configurator

GUI authoring for programs, system environment/PATH, Registry, firewall, policies,
services, networking, and local accounts. Raw Nix is available through a hidden
advanced editor. GUI and custom Nix feed the same validated configuration path;
incompatible definitions fail visibly before deployment.

Current requirements: [SRS](../../../../docs/scope/SRS.md).

This folder reserves ownership only. No implementation or new scope commitment
is introduced by this layout.
